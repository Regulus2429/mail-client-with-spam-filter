## 执行环境与方法

2026-10-27，在本机 Windows、Python 3.11、aiosmtpd 1.4.6 下运行自动集成测试。测试通过本机 TCP 启动真实 SMTP 和 POP3 服务，创建临时账号、邮件和证书；使用 Python 标准库客户端通信，不依赖外部邮箱。

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

需要 OpenSSL 在 PATH 中。测试文件将临时生成自签名证书并在完成后清理测试数据。明文服务启动时 aiosmtpd 会提示认证未加密，这是明文对照的预期提示；证书拒绝测试可能产生 TLS 握手失败日志。

## 验证内容

- 明文 SMTP/POP3 收发：中文主题、正文中以点开头的行、HTML、中文附件文件名；比较附件收发前后的 SHA-256 哈希。
- 检查错误密码被 SMTP 和 POP3 拒绝、邮箱隔离、重复下载按 UID 跳过。
- POP3 同邮箱锁、删除后异常断开回滚、RSET 撤销和 QUIT 提交。
- SMTP STARTTLS 和 POP3 TLS 连接；不受信任证书及主机名不匹配时客户端拒绝。
- 使用独立的伪造证书启动本地 POP3 代理，验证客户端拒绝代理并仍能连接真实服务器；验证 SMTP 的 PLAIN 和 LOGIN 两种认证以及 Windows 上的通配地址监听。
- 10 个账号同时发送和接收，检查每个邮箱邮件数量与主题。
- 实际执行命令行的账号创建、发送、列表、下载、查看和附件提取流程。

## 2026-10-28 单机补充测试

测试在同一台 Windows 电脑上进行，服务器与客户端通过 `127.0.0.1` 通信。使用临时数据库、账号和自签名证书；并发测试中的每个账号分别向自己的邮箱发送并下载一封邮件，检查数量、主题和正文。所有耗时是本机单次测量，包含并发任务的连接、认证、收发和验证，不包含创建账号及启动服务的时间。

| 测试内容 | 实际结果 |
| --- | --- |
| TLS 邮件发送和下载，两个收件人 | 2/2 个邮箱各收到一封邮件，两个投递 UID 不同；发件人、收件人和接收时间已写入 SQLite |
| TLS 邮件含中文纯文本、HTML 和三个附件 | 两个收件人下载后正文和附件文件名正确；三个附件的 SHA-256 均一致，其中一个附件为 1 MiB |
| TLS 服务认证和投递限制 | 未先加密的发信、错误密码、冒用发件人和不存在的收件人均被拒绝 |
| 50 个客户端同时操作，明文模式 | 50/50 个客户端完成各自发送和接收，耗时 5.93 秒 |
| 10 个客户端同时操作，TLS 模式 | 10/10 个客户端完成各自发送和接收，耗时 1.59 秒 |
| 完整自动化回归 | 12 个测试通过，总耗时 27.470 秒 |

本次执行的完整测试命令与上文相同；补充测试脚本位于 `tests/test_additional.py`。证书拒绝测试可能使服务端输出预期的 TLS 握手错误日志；明文模式会出现不安全传输的提示。

本次 50 客户端结果适用于单机、明文、小文本邮件，不代表 50 个 TLS 客户端或大附件并发性能。尚需在两台电脑之间完成局域网联调，并制作 Wireshark 抓包和现场中间人代理演示材料。

## 2026-11-01 垃圾邮件过滤与回归检查

使用 Enron-Spam 的 Enron1 预处理英文数据集，过滤空文本、去重后分层划分训练集 3,425 封、验证集 734 封、测试集 735 封。TF-IDF 和多项式朴素贝叶斯模型在该测试集上的准确率为 98.10%；515 封正常邮件中 7 封误判为垃圾邮件，220 封垃圾邮件中 7 封漏判。训练指标和混淆矩阵保存在本机 `models/spam/metrics.json` 和 `models/spam/confusion_matrix.png`，数据和模型不随 Git 仓库分发。

另手工编写 3 封正常邮件和 3 封典型垃圾邮件，经检查提取文本与数据集邮件没有完全重复。通过本机 TLS SMTP 和 POP3 实际发送、接收后，6 封均按预期分类并保存，垃圾箱列出 3 封，重复收信下载 0 封。这是小样本流程检查，不代表真实环境的分类准确率。同一数据集的近似重复邮件可能使随机划分的测试结果偏乐观，也不能将英文语料结果推广到中文邮件。

再次执行上述完整自动化测试命令，17 项测试通过。测试中的明文认证告警及证书拒绝时的 TLS 错误属于预期输出。

随后增加客户端 JSON 配置、可读邮件列表和本地编号查看接口，完整回归为 18 项通过。新增测试覆盖配置读取、命令行覆盖配置、本地主题和发件人显示、按编号读取正文、无效编号、不同账号及垃圾箱隔离，以及拒绝密码配置项。原有命令行收发、网络服务和过滤测试继续通过。
