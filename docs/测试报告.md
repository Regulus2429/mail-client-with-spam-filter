# 基础功能测试报告

## 执行环境与方法

2026-10-27，在本机 Windows、Python 3.11、aiosmtpd 1.4.6 下运行自动集成测试。测试通过本机 TCP 启动真实 SMTP 和 POP3 服务，创建临时账号、邮件和证书；使用 Python 标准库客户端通信，不依赖外部邮箱。

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

需要 OpenSSL 在 PATH 中。测试文件将临时生成自签名证书并在完成后清理测试数据。明文服务启动时 aiosmtpd 会提示认证未加密，这是明文对照的预期提示；证书拒绝测试可能产生 TLS 握手失败日志。

## 验证内容

- 明文 SMTP/POP3 收发：中文主题、正文中以点开头的行、HTML、中文附件文件名；比较附件收发前后的 SHA-256 哈希。
- 检查错误密码被 SMTP 和 POP3 拒绝、邮箱隔离、重复下载按 UID 跳过。
- POP3 同邮箱锁、删除后异常断开回滚、RSET 撤销和 QUIT 提交。
- SMTP STARTTLS 和 POP3 TLS 连接；不受信任证书及主机名不匹配时客户端拒绝。
- 使用独立的伪造证书启动本地 POP3 代理，验证客户端拒绝代理并仍能连接真实服务器；验证 SMTP 的 PLAIN 和 LOGIN 两种认证以及 Windows 上的通配地址监听。
- 10 个账号同时发送和接收，检查每个邮箱邮件数量与主题。
- 实际执行命令行的账号创建、发送、列表、下载、查看和附件提取流程。

一次完整运行中 10/10 个客户端发送、接收成功，耗时约 3.65 秒；该数字是本机一次测试的结果，不能代表所有硬件和网络条件。自动测试并不替代双机局域网演示、Wireshark 抓包或现场中间人代理演示。50 用户是作业报告中的测试示例，本次未将其作为已完成结果。
