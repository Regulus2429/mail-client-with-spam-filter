# 垃圾邮件过滤扩展

扩展代码已提供，数据集和训练模型需要在本机准备，且不会随 Git 仓库分发。默认收信不启用分类，基础依赖不包含机器学习库。仅处理新下载邮件，既有邮件不会自动重新分类。以下命令均在项目根目录的 PowerShell 中运行；先按[用户手册](用户手册.md)安装基础环境并创建账号。

## 下载和整理数据

本项目使用 [Enron-Spam 数据集](https://www2.aueb.gr/users/ion/data/enron-spam/)的 Enron1 预处理子集：3,672 封正常邮件和 1,500 封垃圾邮件，语料为英文。首次准备数据时运行以下命令；需要能访问数据集网站。Windows 中需要 `tar` 命令。若 `datasets/mail` 已存在，请跳过这些命令，以免覆盖已有数据。

```powershell
if (Test-Path 'datasets/mail') { throw 'datasets/mail 已存在，请检查后再操作' }
if (Test-Path 'datasets/enron1') { throw 'datasets/enron1 已存在，请检查后再操作' }
New-Item -ItemType Directory -Force datasets | Out-Null
Invoke-WebRequest -Uri 'https://www2.aueb.gr/users/ion/data/enron-spam/preprocessed/enron1.tar.gz' -OutFile 'datasets/enron1.tar.gz' -ErrorAction Stop
tar -xzf datasets/enron1.tar.gz -C datasets
if ($LASTEXITCODE -ne 0) { throw '解压失败，请检查下载文件' }
Move-Item -LiteralPath 'datasets/enron1' -Destination 'datasets/mail' -ErrorAction Stop
```

完成后应有 `datasets/mail/ham/` 和 `datasets/mail/spam/`。数据集下载地址、许可和使用条件应在提交或分发前按发布方说明核实。只保留邮件文件在这两个目录中，说明文件不要放进去；训练脚本不会自动下载数据。

## 安装与训练

先完成上面的数据准备，再执行：

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-spam.txt
.\.venv\Scripts\python.exe train_spam.py --data datasets/mail --out models/spam
```

数据目录的 `ham/` 和 `spam/` 可含子目录，每个文件须是一封原始邮件或带邮件头的文本邮件。重复运行训练会覆盖 `models/spam/` 下同名输出文件；若要保留已有结果，请把 `--out` 改为新的目录。过滤空文本并去重后，数据按类别分层随机划分为训练集、验证集和测试集，比例约为 70%：15%：15%。

训练程序共用客户端的 MIME 文本提取函数，按提取文本去重，拒绝冲突标签；分层划分约 70%/15%/15% 的训练、验证、测试数据，固定随机种子。仅在训练集拟合 TF-IDF，以验证集 Spam F1 选择朴素贝叶斯 alpha，最终测试集评估一次。输出 `model.joblib`、`metrics.json`、`confusion_matrix.png`。矩阵行是真实类别，列是预测类别，顺序为 ham、spam。数据存在近似重复或同一邮件线程时，还应进一步清理或按组划分，避免高估效果。

仅使用英文语料训练时，不应将测试结果推广到中文邮件。Enron1 一次实际训练的结果及局限见[测试报告](测试报告.md)；其他数据或训练环境应以本次生成的指标为准。

## 收信与查看垃圾箱

先按照用户手册启动 TLS 服务并发送新邮件。以下命令使用手册中的本机地址、默认端口和示例账号，收信时输入 Bob 的密码；服务器 IP、端口、证书和账号不同时按实际环境替换。应在首次下载这些邮件时启用过滤：已经下载的邮件不会自动重新分类；可以重新发送新邮件进行演示。

```powershell
.\.venv\Scripts\python.exe -m mailproject fetch --user bob@example.test --ca certs/server-cert.pem --spam-model models/spam/model.joblib --color always
.\.venv\Scripts\python.exe -m mailproject spam-list --user bob@example.test
```

只加载自己训练或可信来源的模型，joblib 模型文件可能执行代码。`--color auto` 默认在终端输出颜色；`always` 强制 ANSI 红色；`never` 禁用颜色但保留 `[SPAM]` 标签。

正常邮件保留在 `downloads/<账号UTF-8十六进制>/`，垃圾邮件放入该目录下的 `spam/`。使用自定义下载根目录时，为 fetch 和 spam-list 指定相同的 `--out`。现有 `view` 命令仍可查看垃圾箱内的 .eml 并提取附件。服务器 `list` 仍列出服务器邮件，不反映本地分类。

`spam-list` 显示本地编号、发件人和主题。可以用 `view --user bob@example.test --folder spam --number 1` 查看当前垃圾箱列表中的第 1 封邮件；文件发生变化后需重新列出。配置文件可以保存收信账号、证书和模型路径，具体示例见[用户手册第 8、9 节](用户手册.md)。

模型每次收信加载一次。模型加载失败或预测/移动失败时提示未分类，原邮件保留；不删除服务器邮件，不改写原始 MIME 内容。去重同时检查普通目录和 spam 目录，即使随后关闭过滤也不会重复下载垃圾邮件。需要人工恢复时，将 .eml 从 spam 目录移动回上一级账号目录，勿覆盖同名文件；已有 UID 会被跳过，不会再次自动移入垃圾箱。

## 验证与演示

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

扩展单元测试使用替身分类器验证 MIME 提取、路由、错误回退、原文保留、跨目录去重和账号隔离，不下载数据，不训练模型。基础集成测试验证真实 SMTP/POP3/TLS 收发。使用真实模型的示例收发验证见[测试报告](测试报告.md)。

现场演示需发送正常邮件和典型垃圾邮件，收信后展示红色 `[SPAM]`、垃圾箱、重复收信跳过，以及正常邮件附件完整性。提交报告时补充实际环境版本、指标和误判分析。
