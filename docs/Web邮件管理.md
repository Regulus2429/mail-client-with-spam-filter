# Web 邮件管理界面

网页是可选的邮件客户端，支持登录、收件箱、垃圾箱、收取邮件、阅读正文、发送邮件及附件上传下载。原来的命令行收发方式仍然可用。网页通过 SMTP/POP3 连接邮件服务，不直接修改服务器数据库。

## 1. 首次准备

以下命令都在项目根目录的 PowerShell 中执行。第一次使用项目时，请先完成[Windows 使用手册](用户手册.md)第 1–3 节：安装基础依赖、创建 Alice 和 Bob 测试账号、准备证书。已有账号和证书时无需重新创建。

安装网页依赖（只需执行一次）：

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-web.txt
```

需要垃圾邮件过滤时，还要按照[垃圾邮件过滤扩展](垃圾邮件过滤.md)安装过滤依赖并训练模型。网页不会自动训练模型，请使用自己生成的可信模型文件。

## 2. 启动邮件服务和网页

打开第一个 PowerShell，在项目根目录启动邮件服务；如果它已经运行，请保持运行，不要重复启动：

```powershell
.\.venv\Scripts\python.exe -m mailproject server --cert certs/server-cert.pem --key certs/server-key.pem
```

再打开第二个 PowerShell，切换到同一项目目录，启动网页：

```powershell
.\.venv\Scripts\python.exe -m mailproject.web --ca certs/server-cert.pem
```

如果要启用过滤，将上一条启动命令替换为以下命令，并将模型路径替换为实际文件路径：

```powershell
.\.venv\Scripts\python.exe -m mailproject.web --ca certs/server-cert.pem --spam-model models/spam/model.joblib
```

在本机浏览器地址栏输入 `http://127.0.0.1:8080`。两个终端都需要保持运行，关闭时分别按 Ctrl+C。网页服务重启后需要重新登录。启动时显示的开发服务器提示是 Flask 的正常提示，本界面用于本机课程演示，不用于公网部署。

网页固定只监听本机。浏览器到网页使用本机 HTTP，网页到邮件服务默认使用 TLS。`--host` 指定的是邮件服务器地址，不是网页监听地址；网页客户端也可以连接其他机器上的邮件服务，但证书必须与该地址匹配。

## 3. 完成一次收发测试

1. 在网页输入 `alice@example.test` 和创建账号时设置的密码，点击“登录”。这不是现实中的邮箱账号，也没有默认密码。
2. 点击“写邮件”，收件人填写 `bob@example.test`，输入主题和正文。需要附件时点击文件选择按钮，可选择多个文件。
3. 点击“发送邮件”，看到“邮件已投递到服务器”后发送完成。收件人必须是本系统已注册账号，不能填写公网邮箱。
4. 点击“退出登录”，改用 Bob 的账号和密码登录。若想同时保留两个账号，可使用另一个浏览器或独立的隐私窗口；同一浏览器普通标签页共用登录状态。
5. 点击“收取邮件”，查看下载数量。点击主题打开详情；附件通过详情中的“下载”链接保存到浏览器下载目录。
6. 启用过滤时，同时检查“垃圾箱”。再次收取同一批邮件通常显示下载 0 封，这是按邮件 UID 去重的正常结果。

网页不会自动定时收信，刷新页面也不会收取新邮件。收件箱和垃圾箱显示已下载的本地邮件；发送操作只投递到服务器，当前版本没有已发送箱、草稿、删除或已读状态。HTML 邮件作为文本显示，不执行其中的标签和脚本。

## 4. 过滤和本地文件

默认下载目录是 `web-downloads`，与命令行默认的 `downloads` 分开。因此同一封邮件可以分别被两种客户端独立下载，服务器原件会保留。退出登录不会删除下载文件。

页面顶部会提示过滤是否启用。模型加载失败时仍允许收信，新邮件保留在收件箱；修复模型路径或依赖后需要重启网页。单封邮件分类失败也会保留原文并显示提示。收件箱中的邮件不一定已经被判定为正常邮件。

过滤只作用于首次下载的新邮件。先未启用过滤下载的邮件，不会因为后来启用过滤而自动重新分类。演示时可以发送新邮件，或者使用新的独立下载目录：

```powershell
.\.venv\Scripts\python.exe -m mailproject.web --ca certs/server-cert.pem --spam-model models/spam/model.joblib --out web-downloads-demo
```

自定义目录可能不在 Git 忽略范围内，不要提交账号邮件、附件或模型。不要让多个网页进程或命令行客户端同时写入同一个下载目录。默认目录已加入忽略规则。

## 5. 常见问题

- 网页打不开：确认第二个终端仍在运行，地址是 `http://127.0.0.1:8080`。端口被占用时使用 `--port 8081`，浏览器也改为 8081。
- 登录失败：先检查第一个终端的邮件服务，再检查账号密码、证书路径和端口。同一邮箱被其他 POP3 会话占用时，结束其他收信操作再试。
- 登录后过了一段时间回到登录页：登录有效期为 30 分钟，到期需重新登录。密码只在网页服务进程内存中临时保存，不写入浏览器 Cookie 或配置文件。退出会使该会话失效；关闭浏览器标签页不等于退出，请主动点击“退出登录”。
- 收信失败：检查服务是否停止、证书是否匹配，或同一账号是否正在命令行收信。已下载邮件会保留，稍后可以重试。
- 发送失败：核对所有收件人均已注册，检查邮件服务与附件。失败提示可能表示部分收件人已经收到邮件，重试前先核实，避免重复发送。重试时需重新选择附件。
- 附件过大：整个网页表单最多 20 MiB，邮件编码后还受 SMTP 服务器大小限制；请减少附件后重试。
- 页面已过期：刷新页面再操作；登录超时后重新登录。切换账号前先保存尚未发送的正文。
- 命令行有邮件、网页没有：两者默认使用不同下载目录，请在网页点击“收取邮件”。服务器已删除的邮件无法重新下载。

## 6. 明文实验与命令参数

仅做本机明文抓包对照时，可以将两个启动命令分别改为：

```powershell
.\.venv\Scripts\python.exe -m mailproject server --plain --smtp-port 1025 --pop-port 1110
.\.venv\Scripts\python.exe -m mailproject.web --plain --smtp-port 1025 --pop-port 1110
```

不要把明文客户端连接到 TLS 端口，也不要在明文实验中使用真实密码。完整参数可以通过以下命令查看：

```powershell
.\.venv\Scripts\python.exe -m mailproject.web --help
```

网页独立使用命令行参数，不读取 `client.local.json`。`--ca` 是可信邮件服务器证书，`--out` 是下载目录，`--spam-model` 是过滤模型路径；这些路径都相对于启动时所在的目录。
