# 课程邮件系统 基础功能

这是一个 Windows 上运行的教学用邮件系统：Python 标准库客户端通过 SMTP 发送邮件、通过 POP3 接收邮件；服务端使用 aiosmtpd 提供 SMTP，并实现与其共享存储的 POP3 服务。支持 MIME 正文和附件、认证、TLS、SQLite 元数据和多客户端并发。此版本不包含垃圾邮件过滤、Web 等扩展功能。

请先阅读 [Windows 使用手册](docs/用户手册.md)，其中包含环境安装、创建账号、证书、收发、附件提取和局域网运行命令。[设计说明](docs/设计说明.md) 说明协议、存储、测试及限制；[测试报告](docs/测试报告.md) 记录目前实际执行的验证结果和可复现命令。

仓库使用 `.gitignore` 排除虚拟环境、邮件、账号数据库、下载文件及证书私钥。请勿提交真实账号密码和私钥。
